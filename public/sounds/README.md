# Ambient Sound Files (Optional Drop-in Replacements)

This Cozy Focus Room features a built-in, continuous Web Audio API synthesizer for all 4 sound modes (Rain with thunder, Fireplace crackles, Forest birdsong, and Library room tone).

You can also place high-fidelity MP3/WAV files directly in this directory:
- `rain.mp3`
- `fireplace.mp3`
- `birds.mp3`
- `library.mp3`

The audio player can play local files or default seamlessly to the high-efficiency, non-repeating procedural synthesizer.
